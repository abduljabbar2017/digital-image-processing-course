# Digital Image Processing Course (17 Weeks)

## Course Overview
A comprehensive 17-week course on Digital Image Processing with hands-on Python laboratory work. Students will learn fundamental and advanced concepts in image processing through lectures, practical labs, and real-world applications.

**Duration:** 17 weeks  
**Lectures:** 2 per week (34 total lectures)  
**Format:** Hybrid (Lectures + Python Labs)  
**Prerequisites:** Linear Algebra, Calculus, Basic Python Programming

---

## Course Objectives
By the end of this course, students will be able to:
- Understand fundamental concepts of digital image processing and formation
- Apply image enhancement and restoration techniques
- Implement image segmentation and feature extraction algorithms
- Work with color image processing and transformations
- Apply morphological operations for shape analysis
- Implement frequency domain processing using Fourier transforms
- Develop practical computer vision applications using Python
- Apply deep learning techniques to image classification problems

## 17-Week Course Schedule

### **Week 1: Introduction to Digital Image Processing**
- **Lecture 1.1:** Course Overview, History, and Applications of Image Processing
- **Lecture 1.2:** Digital Image Fundamentals - Resolution, Color Depth, File Formats
- **Lab 1:** Python Environment Setup, Image I/O, Display and Basic Manipulation
- **Resources:** Slides, Video lectures, Chapter 1 textbook reading

### **Week 2: Image Formation and Sampling Theory**
- **Lecture 2.1:** Image Formation Model, Sampling and Quantization
- **Lecture 2.2:** Aliasing, Nyquist Theorem, Interpolation Methods
- **Lab 2:** Image Sampling, Downsampling, Upsampling, and Interpolation Techniques
- **Resources:** Textbook Ch. 2, supplementary videos on sampling

### **Week 3: Image Enhancement - Spatial Domain (Part 1)**
- **Lecture 3.1:** Histogram Processing, Histogram Equalization, Contrast Stretching
- **Lecture 3.2:** Histogram Matching, Adaptive Histogram Equalization (CLAHE)
- **Lab 3:** Implement Contrast Enhancement, Histogram Manipulation, Interactive Tools
- **Resources:** Example images, code templates, comparison tutorials

### **Week 4: Image Enhancement - Spatial Domain (Part 2)**
- **Lecture 4.1:** Spatial Filtering, Convolution, Correlation Operations
- **Lecture 4.2:** Smoothing Filters, Sharpening Filters, Unsharp Masking
- **Lab 4:** Implement Various Spatial Filters, Filter Design, Performance Analysis
- **Resources:** Filter kernels reference, convolution visualization tools

### **Week 5: Frequency Domain Processing (Part 1)**
- **Lecture 5.1:** Fourier Transform, DFT, Fast Fourier Transform (FFT)
- **Lecture 5.2:** 2D Fourier Transform, Frequency Domain Properties, Phase and Magnitude
- **Lab 5:** Fourier Transform Analysis, Frequency Spectrum Visualization, FFT Performance
- **Resources:** Interactive frequency domain demos, visualization scripts

### **Week 6: Frequency Domain Processing (Part 2)**
- **Lecture 6.1:** Frequency Domain Filtering Concepts, Ideal Filters, Padding Effects
- **Lecture 6.2:** Butterworth Filters, Gaussian Filters, Homomorphic Filtering
- **Lab 6:** Design and Implement Low-pass and High-pass Filters, Band-pass Filtering
- **Resources:** Filter design tools, frequency response plots

### **Week 7: Image Restoration and Denoising**
- **Lecture 7.1:** Noise Models (Gaussian, Salt & Pepper, Speckle), Restoration Theory
- **Lecture 7.2:** Wiener Filter, Median Filter, Bilateral Filter, Non-local Means
- **Lab 7:** Implement Denoising Algorithms, Compare Performance on Noisy Images
- **Resources:** Sample noisy images, restoration metrics (PSNR, SSIM)

### **Week 8: Edge Detection and Boundary Extraction**
- **Lecture 8.1:** Edge Detection Operators - Sobel, Prewitt, Laplacian, Roberts
- **Lecture 8.2:** Canny Edge Detection, Edge Linking, Boundary Following
- **Lab 8:** Implement Multiple Edge Detectors, Compare Results, Parameter Tuning
- **Resources:** Test images, edge detection comparison benchmarks

### **Week 9: Image Segmentation (Part 1)**
- **Lecture 9.1:** Image Segmentation Overview, Thresholding (Global and Adaptive)
- **Lecture 9.2:** Otsu's Method, Multi-level Thresholding, Region Growing
- **Lab 9:** Segmentation Using Thresholding, Interactive Threshold Selection, Region Analysis
- **Resources:** Segmentation datasets, evaluation metrics (Dice, IoU)

### **Week 10: Image Segmentation (Part 2)**
- **Lecture 10.1:** Watershed Algorithm, Marker-controlled Watershed
- **Lecture 10.2:** Clustering-based Segmentation (K-means, Fuzzy C-means, GMM)
- **Lab 10:** Advanced Segmentation Techniques, Multi-class Segmentation, Watershed Applications
- **Resources:** Complex segmentation examples, clustering tutorials

### **Week 11: Morphological Image Processing**
- **Lecture 11.1:** Morphological Operations - Erosion, Dilation, Opening, Closing
- **Lecture 11.2:** Morphological Algorithms, Hit-or-Miss Transform, Skeleton, Pruning
- **Lab 11:** Implement Morphological Operations, Shape Analysis, Object Detection Preprocessing
- **Resources:** Structuring element generators, morphological operation visualizations

### **Week 12: Color Image Processing**
- **Lecture 12.1:** Color Models (RGB, CMY, HSV, Lab, YCbCr), Color Space Transformations
- **Lecture 12.2:** Color Image Enhancement, Pseudo-coloring, Color Quantization
- **Lab 12:** Color Space Conversions, Color-based Segmentation, Color Image Enhancement
- **Resources:** Color space diagrams, color image datasets

### **Week 13: Feature Extraction and Description**
- **Lecture 13.1:** Texture Analysis, GLCM (Gray-Level Co-occurrence Matrix), LBP, SIFT
- **Lecture 13.2:** Corner Detection (Harris, Shi-Tomasi), Feature Descriptors
- **Lab 13:** Extract and Analyze Texture Features, Corner Detection Comparison
- **Resources:** Feature extraction libraries, texture databases

### **Week 14: Feature Matching and Image Registration**
- **Lecture 14.1:** SIFT, SURF, ORB Features and Descriptors
- **Lecture 14.2:** Feature Matching Algorithms, Image Registration, Alignment Techniques
- **Lab 14:** Feature Detection and Matching, Image Registration, Panorama Stitching
- **Resources:** Feature matching examples, registration benchmarks

### **Week 15: Object Recognition and Detection**
- **Lecture 15.1:** Template Matching, Normalized Cross-Correlation, Chamfer Matching
- **Lecture 15.2:** Hough Transform, Circle/Line Detection, Generalized Hough Transform
- **Lab 15:** Object Detection Methods, Hough Transform Applications, Template Matching
- **Resources:** Object detection datasets, detection performance metrics

### **Week 16: Deep Learning for Image Processing**
- **Lecture 16.1:** CNN Fundamentals, Convolution Operations, Pooling, Activation Functions
- **Lecture 16.2:** Image Classification with Pre-trained Models (ResNet, VGG, MobileNet)
- **Lab 16:** Deep Learning Image Classification, Transfer Learning, Model Fine-tuning
- **Resources:** TensorFlow tutorials, pre-trained model zoos, image classification datasets

### **Week 17: Advanced Topics and Final Projects**
- **Lecture 17.1:** Advanced Applications (Medical Imaging, Autonomous Vehicles, Remote Sensing)
- **Lecture 17.2:** Course Review, Best Practices, Future Trends in Image Processing
- **Lab 17:** Final Project Development, Presentations, Peer Review
- **Resources:** Project guidelines, example applications, presentation templates

